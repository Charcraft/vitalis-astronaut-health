# Use of Super Intelligence (SI)

NASA Space Apps 2026 permits SI tools "to accelerate innovation" but not to come up with the idea of how to solve the challenge, and requires a clear indication of **where and how** they were used. This page is that disclosure. The prompts themselves are in [`prompts/`](prompts/README.md).

## Summary

| Area | SI tool | What it did | Human control |
|---|---|---|---|
| Code (backend, desktop UI, tablet bridge) | Antigravity agent; Claude Code | Wrote and refactored most of the Python code from the team's prompts, ran and fixed the tests | The team set the scope, reviewed behaviour on screen, ran the apps and directed every iteration; all releases were approved by a team member |
| Tests | Same | Wrote and ran `unittest` suites (38 tests) and a tablet layout audit | Failures were investigated and fixed; the audit found and fixed a real overlap |
| Documentation | Same | Drafted English documentation, indicator catalogue and this record from verified sources | Every number has a source or a `[TO BE VALIDATED]` tag; the team reviewed the text |
| Research | Agent with web search / automated browser | Located and cross-checked official NASA / space-agency pages | Claims verified against the original page and cited in [`DATA_SOURCES.md`](DATA_SOURCES.md) |
| In-product assistant **L.I.S.** | Optional cloud LLM (user-provided API key) or local Ollama-compatible model | Natural-language wording of answers | **Grounded on local data.** A validator rejects any number not in the snapshot; a deterministic fallback answers offline. The model never decides a triage level. |
| Voice | `edge-tts` (Microsoft neural voices), Windows SAPI, optional local XTTS clone; `faster-whisper` (Whisper "base", local) | Text-to-speech and speech-to-text at run time | Voices are generated at run time; no voice recordings are shipped in this repository. Identifiers such as `jarvis-clone-*` are historical labels for an optional local voice-clone server that is **not** included; without it the app uses edge-tts or Windows SAPI |

## What SI generated in this repository

* **Code:** the Python sources in `backend/`, `desktop/`, `tablet/`, `tests/`, `scripts/` and `vitalis_*.py` were written with SI assistance and reviewed/run by the team. This disclosure and the file headers acknowledge it.
* **Data:** *no* data were generated by SI. The only dataset is NASA OSDR OSD-575, downloaded and normalised by a script. Simulated cabin signals in `recursos/datos/mock/` are explicitly labelled as simulated.
* **Images and video:** the repository contains **no SI-generated images or videos**. The screenshots in `docs/screenshots/` are captures of the running application. The astronaut-style "face" of L.I.S. is drawn procedurally with vector code.
* **Audio:** no pre-recorded audio is shipped. The hospital-style BPM tone and the alarm are synthesised by code (`desktop/voice_engine.py`); the Wellbeing soundscapes use a synthesised noise fallback.
* **3D models:** not SI-generated; they come from open datasets listed in [`DATA_SOURCES.md`](DATA_SOURCES.md).

## What was never delegated

* The choice of challenge, the product concept and its scope (self-assessment, personal baseline, 3D body, emergency mode, on-board assistant, offline-first).
* The selection of clinical indicators and every threshold decision; unvalidated values are labelled, never invented.
* The decision to build native software instead of a web app, and to offer a tablet as a touch client of the same software.
* Final review, testing on real hardware (including an Android tablet) and release approval.

## Safeguards

* **Determinism where it matters:** `backend/triage.py` is a pure function covered by tests; generative models only phrase explanations.
* **No fabricated numbers:** L.I.S. answers are validated against the data snapshot before they are shown or spoken.
* **Secrets:** API keys typed by the user live only in the local settings database (`data/`, git-ignored). Redacted keys appear in the prompt record as `[REDACTED_API_KEY]`.
* **Medical disclaimer:** the app states permanently that it is not a medical device.
* **NASA branding:** none is used or generated.
